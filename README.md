# Fundamentos de Programación

Este repositorio reúne las prácticas y materiales de la asignatura **Fundamentos de Programación**.  
El propósito es que los estudiantes desarrollen habilidades básicas en el análisis y diseño de algoritmos, utilizando **Diagramas de Flujo de Datos (DFD)** y **Subline Text** como herramientas principales.

## Contenido
- Prácticas de DFD  
- Ejercicios con Subline Text  
- Recursos de apoyo y ejemplos  

## Metodología
Las actividades se realizarán de manera práctica y guiada.  
Se incorporará el uso de **Inteligencia Artificial (IA)** como apoyo para generar ejemplos, resolver dudas y facilitar el aprendizaje.

## Objetivo
Que el estudiante adquiera bases sólidas en programación estructurada y en la representación gráfica de algoritmos, aprovechando herramientas modernas de IA para mejorar su desempeño académico.
