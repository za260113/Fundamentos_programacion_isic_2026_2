# Fundamentos de Programacion

Este repositorio contiene las practicas y materiales de la asignatura **Fundamentos de Programacion**.  
El proposito es que los estudiantes desarrollen habilidades basicas en el analisis y diseño de algoritmos, utilizando **Diagramas de Flujo de Datos (DFD)** y **Subline Text** como herramientas principales.

## Contenido
- Practicas de DFD  
- Ejercicios con Subline Text  
- Recursos de apoyo y ejemplos  

## Metodologia
Las actividades se realizaran de manera practica y guiada.  
Se incorporara el uso de **Inteligencia Artificial (IA)** como apoyo para generar ejemplos, resolver dudas y facilitar el aprendizaje.

## Objetivo
Que el estudiante adquiera bases salidas en programacion estructurada y en la representacion grafica de algoritmos, aprovechando herramientas modernas de IA para mejorar su desempeño academico.
