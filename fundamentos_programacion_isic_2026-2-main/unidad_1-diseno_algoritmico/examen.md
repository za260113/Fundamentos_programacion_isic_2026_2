# **Catálogo de Prácticas y Mejoras Solicitadas**

A continuación, se detalla el enunciado base de cada práctica y la instrucción técnica de la mejora que el alumno debe implementar utilizando arreglos unidimensionales.

| Nombre de la Práctica | Enunciado Base | Mejora usando Arreglos Unidimensionales |
| :--- | :--- | :--- |
| **Práctica 01:** Alta de Registro de Estudiante | Diseña un programa que solicite Número de Control, Nombre, Promedio y Estatus de Documentos. Despliega una ficha. | **Arreglos paralelos:** Utilizar arreglos para guardar el Número de Control, Nombre y Promedio de $N$ estudiantes en una sola ejecución. |
| **Práctica 02:** Conversor de Almacenamiento | Dado un valor en GB, calcula el equivalente en MB, TB y KB. | **Arreglo de resultados:** Almacenar las conversiones resultantes (MB, TB, KB) en un arreglo de 3 posiciones en lugar de variables separadas. |
| **Práctica 03:** Punto de Venta Tecnológico | Solicita precios de 3 productos. Calcula subtotal, IVA, suma costo de envío y despliega desglose. | **Arreglo de precios:** Utilizar un arreglo para almacenar los precios de $N$ productos ingresados, iterando para calcular el subtotal. |
| **Práctica 04:** Dimensionamiento de Fibra Óptica | Toma Radio y Longitud de un ducto. Calcula área de la base, área lateral exterior y volumen. | **Arreglo geométrico:** Guardar el resultado del Área de la Base, Área Lateral y Volumen en un arreglo numérico para su impresión final. |
| **Práctica 05:** Calculadora de Promedio Ponderado | Solicita nota en 4 rubros. Calcula la nota final aplicando la ponderación correspondiente mediante una expresión. | **Arreglos de ponderaciones y notas:** Un arreglo almacenará las notas ingresadas y otro paralelo almacenará los porcentajes de ponderación. |
| **Práctica 06:** Servidor de Registro de Tiempo | Recibe segundos totales. Calcula horas completas, minutos sobrantes y segundos restantes. | **Arreglo de tiempo:** Guardar el desglose final `[Horas, Minutos, Segundos]` en un arreglo de tamaño 3. |
| **Práctica 07:** Verificador SLA | Solicita tiempo de respuesta. Evalúa si es menor o igual a la constante de 200 ms y guarda el booleano. | **Historial de SLA:** Guardar un historial de $N$ tiempos de respuesta en un arreglo y otro booleano paralelo para el estado de cumplimiento. |
| **Práctica 08:** Beca de Investigación | Solicita promedio y créditos. Evalúa si el alumno es elegible para la beca e imprime el resultado. | **Arreglos de candidatos:** Procesar los datos de un grupo de estudiantes, almacenándolos en arreglos para dictaminar a todos al final. |
| **Práctica 09:** Monitor de Tolerancia Datacenter | Captura temperatura y humedad. Determina variables lógicas de condiciones Normativas y de Riesgo. | **Registro de sensores:** Usar arreglos para guardar el historial de las últimas lecturas para imprimir un reporte continuo. |
| **Práctica 10:** Calculadora Presupuestal (Integrador) | Solicita datos de un proyecto. Calcula Subtotal, Gastos, Descuento, Total, Impuestos y evalúa viabilidad. | **Arreglo financiero:** Guardar el desglose económico (Subtotal, Gastos, Descuento, Neto, IVA, Total) en un arreglo indexado para el informe. |
| **Práctica 11:** Monitor de Sobrecarga de CPU | Captura porcentaje de CPU. Si la carga > 85.0, muestra advertencia y cambia bandera a VERDADERO. | **Arreglo de picos:** Almacenar las muestras de CPU en un arreglo y recorrerlo al final para mostrar cuántas veces se activó la alerta. |
| **Práctica 12:** Autenticación de Usuario | Solicita un PIN numérico. Si coincide con la constante, muestra "Acceso Concedido". | **Arreglo de PINS autorizados:** Crear un arreglo con múltiples PINs válidos y hacer una búsqueda secuencial para conceder acceso. |
| **Práctica 13:** Clasificador QoS de Red | Solicita un número de puerto y determina su categoría de prioridad QoS usando condicionales anidados. | **Arreglo de puertos evaluados:** Guardar los puertos ingresados en un arreglo y generar un reporte de cuántos puertos por prioridad existen. |
| **Práctica 14:** Dispatcher CLI | Muestra menú de 4 opciones. Captura la opción e imprime la acción correspondiente. | **Arreglo de cadenas:** Almacenar los nombres de las opciones en un arreglo de texto para imprimir el menú mediante un ciclo dinámico. |
| **Práctica 15:** Reintento de Conexión a BD | Simula proceso de conexión. Bucle mientras el contador <= 3 y la conexión no sea exitosa. | **Historial de intentos:** Guardar las contraseñas ingresadas en cada intento fallido dentro de un arreglo para auditoría de seguridad. |
| **Práctica 16:** Acumulador de Transferencia | Solicita tamaño de archivos en MB. Se detiene cuando la suma acumulada alcanza la cuota (100 MB). | **Arreglo de archivos:** Almacenar el tamaño individual de cada archivo descargado en un arreglo para imprimir el peso de cada uno al final. |
| **Práctica 17:** Menú de Consola de Administración | Menú que se repite hasta que el usuario ingresa 0 (Salir). | **Log de acciones:** Guardar un registro de las opciones seleccionadas en un arreglo y mostrar el historial completo al presionar "Salir". |
| **Práctica 18:** Ingesta de Telemetría | Solicita temperatura. Si no está entre -50.0 y 100.0, vuelve a solicitarla hasta que sea válida. | **Arreglo de lecturas correctas:** Almacenar únicamente los datos que superan la validación en un arreglo para garantizar un lote 100% íntegro. |
| **Práctica 19:** Analizador de Logs | Cuenta cuántos registros de un lote corresponden a Éxito (200), Cliente Error (4xx) o Servidor Error (5xx). | **Arreglo de Logs HTTP:** Guardar cada código en un arreglo general y luego recorrerlo contabilizando los diferentes tipos de errores. |
| **Práctica 20:** Procesador de Transacciones API | Solicita transacciones (Depósito/Retiro), valida fondos, acumula totales y cuenta operaciones. | **Arreglo de Movimientos:** Guardar el monto exacto de cada transacción (positivos/negativos) en un gran arreglo de historial de cuenta. |
| **Práctica 21:** Transmisión de Paquetes | Bucle `Para` desde 1 hasta $N$ imprimiendo el envío secuencial de cada paquete. | **Arreglo de buffers:** Almacenar los paquetes virtuales generados en un arreglo antes de simular su iteración y transmisión. |
| **Práctica 22:** Generador de IPs | Genera lista de direcciones IP incrementando el último octeto de 5 en 5 desde un inicio hasta un final. | **Arreglo de Cadenas IP:** En lugar de solo imprimir, ir agregando cada IP generada (como texto) a un arreglo de direcciones. |
| **Práctica 23:** Monitor Ping de Red | Bucle `Para` de 1 a 5, solicita tiempo en ms. Acumula tiempos, calcula promedio e identifica la máxima latencia. | **Arreglo de latencias:** Guardar los 5 tiempos en un arreglo y usar un segundo ciclo para encontrar el valor máximo dentro del mismo. |
| **Práctica 24:** Temporizador Regresivo | Solicita tiempo en segundos. Bucle `Para` descendente hasta 1 imprimiendo segundos restantes. | **Arreglo de tareas de apagado:** Almacenar una serie de procesos a "matar" en un arreglo e iterar sobre ellos coordinándolos con el conteo. |
| **Práctica 25:** Búsqueda Secuencial de PID | Escanea hasta 10 PIDs buscando coincidencia. Detiene la lectura al encontrarlo (bandera). | **Búsqueda en el Arreglo:** Inicializar y poblar un arreglo con los PIDs. El algoritmo de búsqueda iterará sobre los índices de ese arreglo. |
| **Práctica 26:** Recepción por Fragmentos | Bucle `Mientras` descuenta fragmentos recibidos de un remanente total hasta llegar a 0. | **Arreglo de Chunks:** Guardar el tamaño en MB de cada fragmento individual recibido en un arreglo para análisis de intermitencia. |
| **Práctica 27:** Tabla de Potencias | Solicita límite de bits $N$. Bucle `Para` calcula e imprime potencia $2^i$ (direcciones de memoria). | **Arreglo de direcciones:** Guardar cada resultado ($2^i$) en un arreglo de tamaño $N+1$ para poder consultarlo posteriormente. |
| **Práctica 28:** Generador de Matrices ASCII | Solicita filas y columnas. Usa bucles anidados para imprimir un marco bidimensional con asteriscos. | **Arreglo como fila plana:** Crear un arreglo de tamaño $C$, llenarlo de asteriscos y luego imprimir el arreglo completo $F$ veces. |
| **Práctica 29:** Crecimiento de Carga Servidor | Incrementa carga un 20% en cada iteración hasta superar 10,000 peticiones, contando las horas. | **Arreglo de proyecciones:** Guardar la carga proyectada de cada hora transcurrida dentro de un arreglo para generar un reporte histórico. |
| **Práctica 30:** Balanceador de Carga (Integrador) | Procesa $N$ servidores con bucles anidados. Acumula peticiones en MB y rechaza si excede 50 MB por servidor. | **Arreglo de servidores:** Crear un arreglo de tamaño $N$ donde cada posición es un servidor para guardar la carga total final en su índice. |
